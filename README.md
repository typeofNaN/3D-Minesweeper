# 3D扫雷游戏

一个基于Three.js的3D球形扫雷游戏，使用Vite + TypeScript开发。

## 特性

- 🎯 球形六边形网格
- 💣 经典扫雷游戏逻辑
- 🖱️ 鼠标滚轮缩放
- 🔄 鼠标拖动旋转视角
- 🎨 美观的3D视觉效果

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

然后在浏览器中打开 http://localhost:3000

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 操作说明

- **左键点击**：揭开格子
- **右键点击**：标记/取消标记地雷
- **滚轮**：缩放视角
- **按住左键拖动**：旋转球体

## 技术栈

- Vite - 构建工具
- TypeScript - 类型安全
- Three.js - 3D图形渲染
- HTML5 Canvas - 渲染输出
